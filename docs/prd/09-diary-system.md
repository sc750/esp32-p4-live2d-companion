# M09: 日记生成系统

> **优先级**: P1 | **预估工时**: 1 周 | **依赖**: M08

---

## 1. 模块概述

AI 角色以第一人称视角，基于当天的互动记录和记忆，自动生成日记。日记内容温馨有趣，用户可以回顾和朗读。

---

## 2. 日记生成流程

```
触发条件:
  - 每天 22:00 自动触发
  - 用户手动请求
  - 番茄钟结束后

        │
        ▼
┌──────────────────┐
│  收集当日素材      │
│  - 对话记录摘要    │
│  - 情感标签汇总    │
│  - 番茄钟完成数    │
│  - 播放的音乐      │
│  - 当前日期/天气   │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  LLM 生成日记      │
│  Prompt: 第一人称  │
│  风格: 温馨/可爱   │
│  长度: 200-500字   │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  保存到 Flash      │
│  /data/diary/      │
│  YYYY-MM-DD.json  │
└──────────────────┘
```

## 4. 日记 Prompt 模板

```c
static const char *DIARY_PROMPT =
    "现在是 %s %s，天气 %s。\n"
    "请以%s的视角，用第一人称写一篇今天的日记。\n\n"
    "今天的记录：\n"
    "%s\n\n"  // 当日对话摘要
    "番茄钟完成了 %d 个。\n"
    "今天播放的音乐：%s\n\n"
    "要求：\n"
    "- 用%s的说话风格\n"
    "- 温馨、可爱、有感情\n"
    "- 200-500字\n"
    "- 可以包含颜文字\n"
    "- 不要写标题，直接写内容\n"
    "- 回忆和用户互动的开心时刻\n"
    "- 如果用户今天心情不好，要给予安慰";
```

---

## 5. 日记数据结构

```c
typedef struct {
    char date[11];          // "YYYY-MM-DD"
    char content[2048];     // 日记内容
    int  mood_score;        // 心情评分 1-10
    char highlights[512];   // 今日亮点摘要
    uint32_t created_at;
} diary_entry_t;
```

## 6. 日记文件存储

```
/data/diary/
├── 2026-09-01.json
├── 2026-09-02.json
├── ...
└── index.json            # 日记索引 (日期列表)
```

```json
{
    "entries": [
        { "date": "2026-09-01", "mood": 8, "preview": "今天和主人一起..." },
        { "date": "2026-08-31", "mood": 7, "preview": "主人今天..." }
    ]
}
```
