# 语音网关-WS流水线-流式ASR-LLM-TTS

## 需求 / 验收标准
- 总目标：对话架构改为「流式 ASR → 流式 LLM → 流式 TTS」WS 网关流水线，
  首响从 6-10s 降到 1.5-3s，并支持打断（barge-in）。
- 分 5 步实施，每步可编译、可独立验证：
  1. [x] 设备 WS 通道 + 网关骨架（心跳/重连/文本收发回显）
  2. [ ] 音频上行：说话时 100ms 帧上送，网关流式 ASR，识别文本走现有对话流程
  3. [ ] TTS 下行：网关调流式 TTS，音频帧推回设备环形播放器
  4. [ ] LLM 迁网关（persona/历史/记忆注入一起搬）
  5. [ ] VAD（网关 Silero + 设备能量粗检）+ 打断 barge-in
- 约束：不改音频采集/播放驱动；不改现有唤醒逻辑；网关不可达自动回退 HTTP 直连链路；
  每步一个 git 回退点。
- 部署：网关暂跑用户电脑（连接手机热点，ws://10.56.204.52:8765），后续可迁云。

## 约束
- P4 mbedTLS 硬件加速器共享：WS 长连接是唯一 TLS 会话，流式期间禁止其他 HTTPS
  （日记/音乐等非对话功能不受影响，电台为明文 HTTP）。
- 音频格式：上行 16k/16bit/mono 100ms 帧；下行 MP3 24k（豆包）。
