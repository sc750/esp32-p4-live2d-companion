# 音乐页UI-屏幕音乐控制入口

## 需求 / 验收标准
- 主页状态栏新增音乐入口按钮（音符图标），点击进入全屏音乐控制页；返回按钮回主页，音乐播放不中断。
- 音乐页布局（1024×600 三段式）：
  - 顶栏：[返回] ♪ 音乐 + 播放状态文案（播放中/已暂停/已停止，配色区分）。
  - 中部：当前曲名（主题色大字）+ 已播时长（MM:SS）+ 上一首/播放暂停/下一首三个圆形按钮 + 音量滑块（0~100）。
  - 底部：播放列表（序号+曲名，可纵向滚动，当前曲高亮主题色，最多 32 项超出截断）。
- 交互行为：
  - 主按钮按状态发 RESUME/PAUSE/PLAY（停止态时优先播当前曲索引）。
  - 列表项点击播放对应曲目；音量拖动实时下发，程序同步滑块不回发命令（防自激）。
  - 进页面时音量滑块对齐服务真实值（串口改过音量也不失配）。
- 分层约定（同 scr_home）：UI 只画 + 发回调；编排层 main_app.c 注入回调并翻译为 music_service API；状态由编排层按 1s 节拍经 ui_bridge（持锁）喂入。
- 状态刷新省电：scr_music_set_state 内部"值未变不重绘"+ 页面隐藏直接返回两道闸门。

## 约束
- 线程模型：scr_music 非创建入口一律经 ui_bridge 持 esp_lv_adapter 锁调用，禁止绕桥直调（本次 EXECUTE 已补 ui_bridge_set_music_playlist 修复绕锁问题）。
- UI 层不 include music_service.h（命令枚举自带 scr_music_cmd_t，编排层翻译）。
- 电台名/页面文案的新汉字须加入 tools/gen_nino_font.py 的 CHARSET 并重新生成字体。
- 编译零 error / 零 warning；App 分区占用不超过上限（当前 39%）。
