# 美术素材目录（assets/art/nino）

放三玖（中野三玖）的 AI 生成图。`tools/rigpack.py pack assets/art/nino` 会把它们
打包成固件用的 `assets/character_01.rigbin`。

## 需要的图片

| 文件名 | 内容 | 触发的表情 | 必需 |
|---|---|---|---|
| `Base.png` | 全身立绘，正面站立，双手自然下垂，**纯白背景**，长边≥1024 | （基础层） | ⭐必需 |
| `eyes_closed.png` | 闭眼版（只改眼睛） | 眨眼 / 摸头蹭蹭 | 推荐 |
| `eyes_smile.png` | 笑眼 ^_^ 版（只改眼睛） | 害羞低头 / 大笑 | 推荐 |
| `eyes_wide.png` | 惊讶圆眼版（只改眼睛） | 被戳身体 | 推荐 |
| `mouth_half.png` | 嘴微张版（只改嘴） | idle 说话串 | 推荐 |
| `mouth_open.png` | 嘴张开版（只改嘴） | 说话 / 大笑 | 推荐 |
| `mouth_pout.png` | 嘟嘴版（只改嘴） | 闹脾气 | 推荐 |
| `blush.png` | 腮红版（只在两颊加红晕，其余与 base 一致） | 害羞系叠加 | 推荐 |
| `arm_wave.png` | 单手挥手版（只改手臂） | 预留，暂未接入 | 可选 |

## 触摸手势 → 表情对照（固件 rig_rig.c / rig_lvgl.c）

| 手势 | 表情 | 用到的图层 |
|---|---|---|
| 单击头部 | 害羞低头（2s） | blush + eyes_smile + 头下移 4px |
| 按住头部 ≥600ms | 蹭头（持续到松手） | blush + eyes_closed + 左右轻晃 |
| 单击身体 | 惊讶（1.2s） | eyes_wide + 头上抬 2px |
| 双击角色任意区 | 大笑（1.5s） | eyes_smile + mouth_open |
| 按住身体 ≥1.2s | 闹脾气嘟嘴（持续到松手） | mouth_pout + 摇头 |

## 生成提示词参考（豆包/即梦）

- base：`动漫风格全身立绘，中野三玖（五等分的新娘），粉色长发齐刘海，蓝色耳机，
  米色开衫校服，正面站立，双手自然下垂，纯白背景，全身完整，高质量`
- 变体：上传 base 后用编辑功能，**一次只改一个部位**，例如：
  - `把眼睛改成开心眯起的笑眼 ^_^，其他一切保持不变`
  - `只在两边脸颊加上淡淡的粉色腮红，其他一切保持不变`
  - `把嘴巴改成嘟起来的生气样子，其他一切保持不变`

## 约定（差分切层的命根子，违反 = 打包出来是花屏）

- 变体图必须与 base **同一构图**（用图生图编辑，不要重新生成）
- **一次只改一个部位**——差分切层靠"没变的部分"对齐，一次改两个部位
  会被切成一整块大补丁，没法独立控制
- 背景纯白（工具按阈值抠图）
- `parts.json`（可选）：`{"neck_ratio": 0.35, "max_height": 480}` 指定头/身
  切分线比例和降采样目标高度（当前 480 与固件 fit_h 一致，1:1 渲染无二次缩放）
- 仅限个人学习用途，勿商用
