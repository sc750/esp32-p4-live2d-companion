# 美术素材目录（assets/art/nino）

放三玖（中野三玖）的 AI 生成图。`tools/rigpack.py pack assets/art/nino` 会把它们
打包成固件用的 `assets/character_01.rigbin`。

## 需要的图片（按优先级）

| 文件名 | 内容 | 必需 |
|---|---|---|
| `base.png` | 全身立绘，正面站立，双手自然下垂，**纯白背景**，长边≥1024 | ⭐必需 |
| `eyes_closed.png` | base 的闭眼版（图生图编辑，只改眼睛） | 推荐 |
| `mouth_half.png` | base 的嘴微张版 | 推荐 |
| `mouth_open.png` | base 的嘴张开（笑）版 | 推荐 |
| `arm_wave.png` | base 的单手挥手版 | 可选 |

## 生成提示词参考（豆包/即梦）

- base：`动漫风格全身立绘，中野三玖（五等分的新娘），粉色长发齐刘海，蓝色耳机，
  米色开衫校服，正面站立，双手自然下垂，纯白背景，全身完整，高质量`
- 变体：上传 base 后用编辑功能 `把眼睛改成闭上的，其他一切保持不变`

## 约定

- 变体图必须与 base **同一构图**（用图生图编辑，不要重新生成）
- 背景纯白（工具按阈值抠图）
- `parts.json`（可选）：`{"neck_ratio": 0.42}` 指定头/身切分线（占图高比例）
- 仅限个人学习用途，勿商用
